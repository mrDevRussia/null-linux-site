About

Small, on purpose

Null Linux is a from-scratch distribution built on Buildroot with a BusyBox userland. There is no desktop environment to strip out and no upstream distro underneath it — every binary that ships is there because it was put there on purpose.

Right now it's genuinely simple: a set of install tools to get the system onto a disk, and Bit Studio, a small text editor for writing code directly on the system. It's a solo project, actively developed, currently in beta — more tools land as they're built, not before.

Install

Manual installation

Null Linux Dyson installs manually from a Live environment with fdisk, extlinux, and a plain filesystem archive — no guided installer, just the disk tools directly. Replace <target-disk> (e.g. /dev/sda) and <target-partition> (e.g. /dev/sda1) with your own device names — run lsblk first to confirm them.

Prerequisites

  • Kernel image — the compiled bzImage binary.
  • Root filesystem — rootfs.cpio or rootfs.ext2, containing system binaries, libraries and init.
  • Bootloader binaries — syslinux / extlinux utilities and mbr.bin.

  1. Partition the disk. Launch fdisk on the target drive.

    fdisk <target-disk>

    Inside fdisk:

    # clear the partition table
o

# create a new primary partition, using the full disk
n
p
1


# mark it bootable
a
1

# review, then write and exit
p
w

  2. Format and mount the new partition as ext2.

    mkfs.ext2 <target-partition>
mkdir -p /mnt/null
mount <target-partition> /mnt/null
mkdir -p /mnt/null/boot

  3. Install the bootloader. Write extlinux to the boot directory, then write the MBR code to the disk itself.

    extlinux --install /mnt/null/boot
cat /usr/share/syslinux/mbr.bin > <target-disk>

  4. Deploy the kernel into the boot directory.

    cp bzImage /mnt/null/boot/bzImage

  5. Extract the root filesystem into the mounted partition.

    cd /mnt/null
cpio -idv < /path/to/rootfs.cpio

  6. Configure the bootloader by UUID, not device name, so it survives hardware changes. First look up the partition's UUID:

    blkid <target-partition>

    Then write extlinux.conf using that UUID:

    cat > /mnt/null/boot/extlinux.conf << 'EOF'
DEFAULT linux
LABEL linux
  LINUX /boot/bzImage
  APPEND root=UUID=<YOUR-PARTITION-UUID> rw
EOF

  7. Finalize and reboot. Flush writes, unmount, and restart.

    sync
umount /mnt/null
reboot
Remove the installation media as soon as the reboot starts. The firmware loads the MBR, hands off to extlinux, extlinux loads bzImage by its UUID, and control passes into the standalone Null Linux Dyson system.
